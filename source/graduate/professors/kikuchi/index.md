## 主要研究什么？

菊地浩平的核心研究对象是<strong>人形，以及人类为什么不断创造、观看、操纵并赋予人形生命感</strong>。

其研究从现代人形剧、电视人形剧出发，但并不局限于传统意义上的Puppet。

早稻田大学公开资料明确显示，其广义的人形文化研究还包括：

- ぬいぐるみ
- 着ぐるみ
- Doll
- 人形剧
- Android
- Robot
- Avatar
- 虚拟空间中的分身
- 人工身体
- 「ぬい撮り」
- 各类人形化、拟人化的文化现象

因此，这里的“人形”不是一种狭窄的传统艺术Genre。

它更接近一个非常大的问题：

<strong>
人为什么会把没有生命的东西看成“像活着一样”？<br>
为什么我们会对人形产生感情？<br>
角色为什么需要身体？<br>
虚构角色怎样获得实体？<br>
人和人工身体之间到底是什么关系？
</strong>

<div class="professor-note">
<strong>理解这个方向的关键：</strong>
菊地浩平研究的不是单纯的“玩偶收藏文化”。人形可以被理解为一种介于<strong>人 / 非人、生命 / 无生命、现实身体 / 虚构角色</strong>之间的Media。
</div>

## “人形”为什么与宅文化关系很近？

<div class="professor-note">
动漫游戏文化里有一个非常普遍、但很容易被忽视的问题：

<strong>角色并不会永远停留在二维Image里。</strong>
</div>

一个角色可以从：

<strong>
漫画 / 动画 / 游戏中的Image<br>
↓<br>
Figure / Doll / ぬいぐるみ<br>
↓<br>
着ぐるみ / Mascot<br>
↓<br>
Avatar / Virtual Body
</strong>

不断获得不同形式的“身体”。

于是就会产生很多问题：

- 为什么我们希望拥有角色的实体？
- 为什么ぬいぐるみ会被当成有性格的伙伴？
- 为什么人会给ぬい拍照、旅行、吃饭？
- Figure和Doll为什么不仅仅是“商品”？
- 二维角色变成立体Object以后发生了什么？
- 着ぐるみ里面明明有人，为什么观众仍然把它看成角色？
- Avatar究竟是“我”，还是另一个身体？

这些问题都可以进一步进入：

<strong>
Character<br>
Body<br>
Object<br>
Media<br>
Personhood<br>
Representation
</strong>

之间的关系。

这正是菊地浩平的人形文化研究与宅文化最有潜力发生连接的位置。

## 什么是“人工身体”？

菊地浩平近年来一个特别值得本站关注的方向，是<strong>人工身体</strong>。

早稻田开设的「人工身体論ゼミ」把这个概念定义得非常宽。

其中包括：

- 传统人形
- 土偶
- 着せ替え人形
- 球体关节人形
- 人形剧
- 着ぐるみ
- ぬいぐるみ
- Doll
- Virtual Idol
- Automaton
- Robot
- Android
- Cyborg
- Avatar

这些对象看似完全不同，但都有一个共同点：

<strong>它们都创造了一个“不是普通人体，却像某种身体”的存在。</strong>

<div class="professor-note">
对于宅文化研究来说，这个概念尤其有价值，因为角色文化中大量现象其实都可以重新理解成“人工身体”的生产与消费。
</div>

例如：

初音未来有没有身体？

游戏Avatar是不是玩家身体的延伸？

Character Doll究竟是角色的复制品，还是角色的一种身体？

着ぐるみ角色与里面的演员是什么关系？

Virtual YouTuber的Avatar属于谁的身体？

这些都不是单纯的商品研究，而可以变成非常明确的表象文化问题。

## ぬいぐるみ与「生きてるみ」

菊地浩平近年来还持续研究ぬいぐるみ文化。

其中一个很有意思的问题是：

<strong>
为什么我们明知道ぬいぐるみ没有生命，却很难完全把它当成普通物体？
</strong>

例如很多人会：

- 给ぬい取名字
- 和ぬい说话
- 带ぬい旅行
- 给ぬい拍照
- 觉得把它扔掉很残忍
- 感觉它“在看着自己”

这里出现了一种介于：

<strong>
Object
与
Living Being
</strong>

之间的状态。

这种“像活着一样”的感觉，也可以帮助理解：

<strong>
角色为什么能够超越作品本身，与现实中的人建立长期情感关系。
</strong>

因此，「ぬい活」「ぬい撮り」并不仅仅是Fans的娱乐行为，也可以成为研究角色、Object、人格化与情感关系的重要文化现象。

## Avatar为什么也属于“人形文化”？

<div class="professor-note">
如果把人形只理解成木偶或玩具，Avatar看起来似乎完全属于另一个领域。

但从“人工身体”的角度看，两者其实存在非常有趣的连续性。
</div>

Avatar也是：

<strong>
一个代表“我”或“某个角色”的人工身体。
</strong>

现实身体无法直接进入虚拟空间。

因此我们需要一个：

- Image
- Character
- Model
- Avatar

替我们存在。

菊地浩平近年来已经公开讨论过：

<strong>「人形としてのアバター――仮想空間を生きるもうひとりのあなた」</strong>

也就是直接把Avatar放进人形文化的框架中思考。

这使他的研究不仅能够处理传统人形，还可能继续连接：

<strong>
Virtual Culture<br>
Avatar Culture<br>
VTuber<br>
Digital Character<br>
Virtual Body
</strong>

等当代问题。

不过，具体的VTuber或Digital Culture题目是否适合指导，仍然需要根据研究计划进一步确认。

## 与石岡良治有什么区别？

<div class="professor-fit-grid">

<div class="professor-fit-card">
<h3>石岡 良治</h3>
<p>
更偏向Image、视觉文化、Popular Culture与批评理论。Character可以作为视觉文化与流行文化现象进行分析。
</p>
</div>

<div class="professor-fit-card">
<h3>菊地 浩平</h3>
<p>
更偏向角色如何获得人工身体，以及人类如何与人形、Doll、ぬい、着ぐるみ、Android和Avatar建立关系。
</p>
</div>

</div>

因此：

如果问题是：

<strong>
某个角色Image如何在Popular Culture中形成？
</strong>

可能更接近石岡良治。

而：

<strong>
为什么人希望让这个角色拥有实体身体？<br>
角色变成Doll、ぬい或Avatar以后发生了什么？
</strong>

则会明显靠近菊地浩平。

## 与須川亜紀子有什么区别？

<div class="professor-fit-grid">

<div class="professor-fit-card">
<h3>須川 亜紀子</h3>
<p>
更偏向Fan / Audience Studies、2.5次元、Gender与Popular Culture实践，关注Fans如何观看、参与并形成文化实践。
</p>
</div>

<div class="professor-fit-card">
<h3>菊地 浩平</h3>
<p>
更偏向人形／人工身体这一媒介与存在本身，以及人为什么会把Object感知为角色、身体甚至具有生命感的存在。
</p>
</div>

</div>

例如同样研究「ぬい活」：

如果问题是：

<strong>
Fans怎样通过ぬい活动形成社群与身份？
</strong>

可能更靠近Fan Studies。

而如果问题是：

<strong>
为什么Fans会把ぬい感知为具有角色人格的存在？<br>
角色为何能够通过ぬい获得一种人工身体？
</strong>

则更靠近菊地浩平的人形文化研究。

## 本站判断

<div class="professor-editorial">

对于本站而言，菊地浩平最有价值的地方，是为<strong>角色文化</strong>提供了一条非常不同于传统动画漫画作品分析的研究路径。<br><br>

很多宅文化研究都会遇到“角色如何超越作品”的问题。角色可以成为Figure、Doll、ぬいぐるみ、着ぐるみ、Virtual Idol或者Avatar，并在现实生活中继续被观看、触摸、携带和赋予人格。<br><br>

菊地浩平的人形文化与人工身体研究，正好提供了理解这些现象的一套独特入口。<br><br>

尤其适合考虑<strong>Doll、ぬい、角色实体化、人工身体、着ぐるみ、Avatar以及虚拟身体</strong>等问题的考生。<br><br>

但是，如果研究只是普通动画作品分析、漫画史、Fan统计或产业消费，并没有进入人形、Object、身体或角色实体化问题，则不能因为对象属于宅文化便自动判断为匹配。<br><br>

本站因此将其定位为：<strong>角色实体化 / 人工身体 × 人形文化方向的直接高匹配教师</strong>。

</div>
